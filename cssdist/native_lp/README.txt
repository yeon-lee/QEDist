Lifted-product search engine

This profile uses the CSS search inside each branch. The additional
anchor-site option starts roots at a specified whole-orbit boundary and keeps
all physical coordinates preceding that boundary available. A partial root
range alone cannot establish a full-sector exclusion. The Python campaign
reconstructs a second matrix for the constituent kernel modulo the stabilizers
trivial in every stripe. An exclusion requires both sets of roots and all
their shards to complete. See ../../docs/lp-block-search.md.

An optional symmetry-file supplies physical permutation generators. The native
engine verifies their action on both row spaces and the anchoring block before
computing joint orbits. The Python layer also checks the induced stripe actions.

The proposed-additions=on flag applies the parent's weighted inequality to the
next qubit in either subproblem. New public certify runs supply it by default.
Use --no-proposed-additions to disable the test. Resume inherits the saved
setting when neither public flag is supplied. Omitting the native flag means
disabled, preserving saved command behavior.
