# Citation and source provenance

The methods manuscript is **QEDist: Practical Exact Distance Certification
for Stabilizer Codes**, by Jong Yeon Lee. The software citation records the
author and release version. [Software citation](../CITATION.cff)

Source code and issue tracking are available in the QEDist repository.
[QEDist repository](https://github.com/yeon-lee/QEDist)

The search builds on the earlier construction study, which can be cited as:

```bibtex
@misc{lee2026designinggroupvaluedcodesregular,
  title={Designing Group-Valued Codes with Full Regular Low-Weight Bases},
  author={Jong Yeon Lee},
  year={2026},
  eprint={2610.06820},
  archivePrefix={arXiv},
  primaryClass={quant-ph},
  url={https://arxiv.org/abs/2610.06820},
}
```

The current search engines build on the author's
[regular-logical-frames implementation](https://github.com/yeon-lee/public-regular-logical-frames).
The CSS, LP and circuit source directories record their respective ancestry.
Cite the software version used for a computation.

When using a published benchmark, also cite its construction source. The
evidence catalogue records this per input. For the 1,122-qubit example, this is
Zhou, Gu, Eisert and Zhao, *Parallel algebraic surgery for qLDPC codes with
constant shuttling depth*, [arXiv:2609.39874](https://arxiv.org/abs/2609.39874),
instance III. Certifying its distance does not make it a new construction.

Imported comparator software retains its original notices in the frozen
research archive. A citation does not replace a software license; see
[NOTICE.md](../NOTICE.md).
